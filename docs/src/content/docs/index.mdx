## Everything a server needs

<CardGrid stagger={true}>
	<Card title="Typed tools" icon="setting">
		Register raw JSON handlers or typed procs, and let nimwire derive the MCP
		input and output schemas at compile time.
	</Card>
	<Card title="Resources and prompts" icon="open-book">
		Static and templated resources with text or binary contents, plus typed
		prompts with completion hooks.
	</Card>
	<Card title="Stdio and HTTP" icon="rocket">
		Serve newline-delimited JSON-RPC over stdio, or adapt Streamable HTTP
		requests into any web framework.
	</Card>
	<Card title="Production controls" icon="approve-check">
		Bearer authorization, bounded security limits, cancellation, progress,
		deadlines, and optional request observability hooks.
	</Card>
</CardGrid>
